# Zjywill Tap

## How do I install these formulae?

`brew install zjywill/tap/<formula>`

Or `brew tap zjywill/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "zjywill/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
